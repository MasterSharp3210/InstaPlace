# InstaPlace
Simple fastplace injectable your Minecraft

# How to compile
To compile the .dll file you can click on Compile as release x64 in your Visual Studio. For the java injector, you have to open a terminal into the injector folder and write: `javac -source 1.8 -target 1.8 -cp "lib/jna-5.13.0.jar;lib/jna-platform-5.13.0.jar" Main.java`
